# 7.3 Power Stroke manuals and tech PDFs

Pulled 2026-10-20 from the 73psd.com Manuals page (https://73psd.com/maintenance/manuals/) and the factory specs page. Saved here so they don't disappear.

## Factory Ford / International documents

| File | What it is |
|---|---|
| `1999-Ford-F-SuperDuty-Workshop-Manual-7.3-Engine.pdf` | Ford Workshop Manual, Powertrain Engine section, 1999 F-250 to F-550. Torque specs, clearances, teardown and assembly procedures. First half covers up to Dec 1998, second half Dec 1998 and newer. THE reference for Family Machine's clearances. |
| `1994-98-7.3-Features-Description-Service.pdf` | Ford/International service training book for the 94-98 engine. |
| `1998-99.5-SuperDuty-7.3-Features-Description-Service.pdf` | Same, for the 98-99.5 Super Duty engine. Covers the changes to the 99 engine (intercooler, wastegate, split-shot injectors). |
| `1999.5-DIT-Engine-Update.pdf` | International update bulletin on the 99.5 DIT engine changes. |
| `1999-Diesel-Diagnostic-Subroutines.pdf` | Ford diagnostic subroutines for the 99 diesel. |
| `2000-OBD-System-Operation-Summary-7.3.pdf` | Ford/International OBD system operation summary, 2000 7.3. Sensor and PCM logic. Useful when wiring a standalone harness in the F600. |
